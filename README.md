# 今日のAI謎

承認済みの一枚謎を掲載する静的サイト。AstroのコンテンツコレクションでJSONを検証し、トップ・年・月・日別ページを自動生成します。回答判定はブラウザー内で行います。公開データとソースから解答を閲覧できる仕様です。

## 開発

Node.js 22.23.4以降（CIは24系）とpnpmを使用します。

```sh
pnpm install
pnpm dev
pnpm build
pnpm preview
```

## 問題の追加と公開

1. 所有者の公開承認を得る。
2. `public/images/YYYY-MM-DD.png` に画像を追加する。
3. `src/content/puzzles/YYYY-MM-DD.json` に日付、承認フラグ、版、画像パス、代替テキスト、受理する答え、表示用解答、ヒント配列、解説を追加する。既存のJSONを形式の参考にする。
4. `pnpm build` と表示・ヒント・回答判定を確認する。
5. 承認された更新をmainへpushするとGitHub ActionsがGitHub Pagesへ公開する。

日付の重複・不正な日付・空の解答・画像不足・未承認・未来日付の原稿はビルド時にエラーにします。下書き・練習記録・認証情報・第三者資料をこの公開リポジトリに入れません。日付が変わっても公開がなければ、トップは掲載済みの最新問題を実際の日付とともに表示します。

現在はGitHub PagesのプロジェクトURLを使用します。独自ドメインへ移す場合はPagesとDNSを設定し、Astroのsiteとbaseも変更します。
